# 使用与兼容说明

版本：Shanghai Operations 0.8.1（开发预览）；模组 ID：`leovan-shanghai-operations`。

社区已于北京时间 2026-10-28 [接受当前 PVG-only 范围并合并申请](https://github.com/Subway-Builder-Modded/registry/pull/13183)。0.8.1 修正社区版本识别；仍为开发预览，普通玩家高级启用流程和长时间运营验收尚未完成。社区接收不等于稳定性验收完成。

## 环境

- 已取得并能正常运行的上海 PVG 地图；地图本体在 [原地图仓库](https://github.com/LeoVan1412/shanghai-pvg)。
- 既有原生专项测试使用 Subway Builder 1.7.2。manifest 沿用 `>=1.7.0` 的声明范围，但其他版本并非都已实测。
- 目前不支持社区已有 SHA 地图。维护者已确认跨地图兼容不是本次接收的必要条件。
- 先保留完整进度备份，使用独立测试进度。与同 ID 的旧版二选一，不能重复安装。

## 审核包

ZIP 根目录包含 `manifest.json`、`index.js`、`README.md`、`LICENSE` 和 `LICENSE-DATA.md`。地图、线网存档和原生游戏文件不在其中。

可将包交给支持本地模组导入的加载器进行独立测试；不同加载器版本的导入入口需以实际界面为准。本仓库不会自动修改本机安装或存档。

## 默认流程

1. 在游戏原生路线编辑器创建线路并选择沿线车站。
2. 进入 PVG 后点击顶部 Network 图标，打开“上海线路规划”。
3. 选择线路和普通 / 快车 / 急行；需要时选择兼容且有唯一连通端点的直通线路。
4. 查看停站、实际轨道上的地图预览，以及配车建议。
5. 点击“应用为新增服务”，检查实际上线列车数。
6. 补车前确认报价；撤销时使用“撤销这次方案”。

购入车厢会保留在库存，撤销不虚构退款。后续手动修改可能阻止自动撤销。保留原线路对象并不保证新增服务不会影响共享区段的运行效率。

## 高级能力的边界

2/4/6/8 股道模板、自动增加通过线、动态越行及离站保护目前属于开发接口，不会仅因安装而自动开启。跳停服务本身不证明发生了越行。任意站型扩建、复杂咽喉和长时无死锁运行尚未完成全面验收。

详细历史说明见 [原候选能力记录](LEGACY_CAPABILITIES_2026-10-01.md)；当前发布判断以 [验收状态](ACCEPTANCE_STATUS.md) 为准。
