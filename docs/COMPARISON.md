# 独立玩法模组的具体区别

## 项目定位

Shanghai Operations 的交付物是运营代码和安装包。它使用既有 PVG 地理底图；本次拆分没有新增人口、就业或实测通勤数据，也不申请以运营功能提高地图的数据质量评级。

同一条既有线路可以先预览快慢停站和配车，再应用为独立原生服务；撤销按本工具持有的方案凭据处理。这条完整操作流程是本项目的主要审核对象。

| 玩家任务 | 本项目提供 | 验证范围与限制 |
| --- | --- | --- |
| 选择制式 | PVG 内五档轨道和车辆，80/120/160/200/300 km/h | 游戏平衡值；未主张比已有车型模组更真实 |
| 组织服务 | 普通、快车、急行与兼容直通组合 | 要求真实连通、车型兼容和原生寻路通过 |
| 设置站型 | 按实体站组、独立走廊和既有设施给出站型 | 缺设施明确标待改造；普通 UI 未完成任意枢纽扩建 |
| 选择编组和数量 | 运行时间、站台长度、库存与其他服务占用参与建议 | 计划数量与实际上线分开；不是实测需求最优化 |
| 应用和撤销 | 创建独立原生服务，并保存归属凭据 | 手动修改会限制撤销；购车不虚构退款 |
| 自动接轨 | 增加独立通过线、原生接入、专属撤销 | 仅开发接口和有限场景验收 |
| 动态越行 | 保留预留和实体保护，检查整列车长＋25 m 出口及车尾清空 | r16 只核验 3 次真实越行；长周期及多站型未完成 |

## 与已存在模组的重叠

已有车型、速度分级、模式管理、轨道导入和限制调整类模组。本项目承认这些共性，审核重点应放在线路、站型、配车、原生应用及撤销的整合。

[2026-10-01 具体对照记录](LEGACY_COMPARISON_2026-10-01.md)引用了 Chinese Trains、Intercity/HSR、Mode Manager、Citymapper 和 Train/Track Anarchy 当时的公开说明。该记录是固定日期的说明对比，不是对它们最新代码的全面审计，也不构成“独家”或“优于全部模组”的结论。

## 旧地图审核关系

[原地图 PR #9355](https://github.com/Subway-Builder-Modded/registry/pull/9355)因未体现对已有上海地图的数据质量提升而被拒。本项目申请走独立玩法模组类别；地图质量复核仍属于原地图项目。

当前 PVG 尚未列入社区目录，且本模组尚不支持 SHA。提交材料必须披露该依赖；新仓库本身不会解除依赖或保证上架。
